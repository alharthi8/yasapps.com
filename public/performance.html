ENGINEERING NOTES · 10 NOVEMBER 2026

Less noise.
More evidence.

We want Yas apps to feel light and responsive. Here is what we can currently say, and how we plan to measure progress.

What is implemented

FactWhat it means
Rust desktop core in both appsYas Mail uses Tauri 2. Yas Browser uses Tao and Wry. Their UI and web content also use web technologies.
Platform web enginesWindows uses Microsoft WebView2; macOS uses Apple WKWebView. Engine processes still use memory and CPU and must be included in measurements.
Yas Browser lazy session restoreSaved tabs can remain as lightweight entries until opened. The browser does not need to load every restored website immediately.
Yas Browser sleeping tabsEligible background website views unload after two minutes. Active downloads, and paused Windows transfers, keep a source view awake. Mac Stealth views are excluded from sleeping. Reloading a sleeping tab can lose unsaved page state.
Windows 20-tab local resource checkThe v0.4.5 report checks retained tab URLs and website-view residency using synthetic local pages. It is not a Chrome/Edge comparison.

What we are not claiming yet

We have not established a general percentage reduction in RAM, CPU, battery use, or overall device load against Chrome, Edge, Outlook, Mailbird, or other clients. In particular, a “70% less” claim would be premature. Rust is an implementation choice, not evidence of a specific performance advantage.

How a fair comparison should work

  1. Use the same device, operating system, power settings, and app versions.
  2. Include the app and all renderer/runtime child processes.
  3. Use the same websites or mail workload, account data, tab counts, and activity sequence.
  4. Measure startup, active work, and idle periods separately; report CPU over a stated interval.
  5. Repeat runs and publish the individual results, median, memory metric, and test conditions.
  6. Explain feature differences—especially sleeping tabs, unloaded pages, and background sync.

A smaller installer does not equal lower RAM use. An unloaded tab does not do the same work as a live page. If a comparison shows a real reduction, we will label the exact metric and workload rather than turn one result into a universal promise.
