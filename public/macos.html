YAS BROWSER · APPLE SILICON PREVIEW

A little Yas.
An early look on Mac.

Yas Browser pairs a Rust desktop core with Apple’s WKWebView. This Mac preview is for early testers who are comfortable with unfinished software. Yas Browser 0.4.7 is available as an experimental preview. It is separate from Windows 1.0 and has fewer features. Yas Mail remains coming soon.

Before you install

  • Apple Silicon only: M1 or newer. Intel packages are not available.
  • Built with a macOS 13 deployment target. Automated launch checks run on macOS 15; builds also run on macOS 26. Older operating-system compatibility is not verified.
  • Yas Browser has an ad-hoc development signature. It is not Apple Developer ID signed or notarized. Gatekeeper may block opening it.

Read Apple’s guidance on safely opening Mac apps ↗. Only proceed if you trust the source. Do not disable Gatekeeper. An update signature verifies that a package was signed with the Yas release key; it is separate from Apple’s checks.

Install the Browser preview

  1. Download Yas Browser 0.4.7 for Apple Silicon ↗.
  2. Extract the ZIP, then move Yas Browser.app into a writable Applications folder, such as ~/Applications.
  3. Open the copied app. Read Apple’s guidance above if Gatekeeper blocks it; this preview is not Apple notarized.

Release notes and checksums ↗. No email registration is required. Yas Mail downloads remain coming soon.

Signed in-app Browser updates

The Browser preview checks GitHub at startup. To check manually, choose Check for app updates in Browser’s menu panel. Approve an available update to download and apply it. The updater checks the signed ZIP and the extracted bundle’s macOS signature before replacing the complete app bundle. Your current session stays open. Save your work, fully quit, and reopen the app when convenient.

The Apple Silicon preview channel is separate from the Windows channel. Browser user settings live outside the app bundle. Keep your own backups while testing early releases. Broader interactive testing is ongoing. This is an early preview for testers, not a claim of Windows feature parity.

What differs from Windows?

Yas Browser: tabs, search, bookmarks, history, lazy session restore, sleeping eligible background pages, Stealth views, file-save downloads, zoom, and print. This first port does not include Windows extensions, password/autofill import, ad-filtering parity, screenshot/PDF export, resumable or tray downloads, or full native menu/shortcut parity. Sleeping tabs may lose unsaved page content and per-tab navigation history. Stealth tabs stay awake and are excluded from history and session restore. Closing the app can stop downloads.

What has been checked?

Browser release automation requires native Rust tests, a frontend/native launch handshake, and signed whole-bundle update installation with damaged-package rejection. These checks do not establish feature parity, comprehensive usability or compatibility with every website. No comparative RAM or CPU percentage is claimed for the Mac previews.
