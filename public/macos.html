APPLE SILICON · EXPERIMENTAL PREVIEWS

A little Yas.
Now on your Mac.

Rust desktop apps, using Apple’s WKWebView. These first Mac previews are for early testers who are comfortable with unfinished software. Downloads are free, with no registration required.

Before you install

  • Apple Silicon only: M1 or newer. Intel packages are not available.
  • Built with a macOS 13 deployment target. Automated launch checks run on macOS 15; builds also run on macOS 26. Older operating-system compatibility is not verified.
  • The apps have ad-hoc development signatures. They are not Apple Developer ID signed or notarized. Gatekeeper may block opening them.

Read Apple’s guidance on safely opening Mac apps ↗. Only proceed if you trust the source. Do not disable Gatekeeper. An update signature verifies that a package was signed with the Yas release key; it is separate from Apple’s checks.

Install once

  1. Choose macOS in the downloads section and download the app’s preview ZIP.
  2. Extract the ZIP. Move Yas Mail.app or Yas Browser.app to a writable Applications folder, such as Applications inside your home folder. A read-only location or a disk image cannot receive an in-app update.
  3. Open the copied app. The Mail preview starts with a demo workspace; connecting a real account is optional.

Checksums are available beside the downloads. Each Browser release ↗ and Mail release ↗ also includes source and detailed release notes.

Updates from inside the app

Both apps check GitHub at startup. To check manually, choose Check for app updates in Mail’s Settings or Browser’s menu panel. Approve an available update to download and apply it. The updater checks the signed ZIP and the extracted bundle’s macOS signature before replacing the complete app bundle. Your current session stays open. Save your work, fully quit, and reopen the app when convenient.

The Apple Silicon preview channel is separate from the Windows channel. User settings and mail data live outside the app bundle. Keep your own backups while testing early releases. If installation fails, download the current ZIP again; a failed integrity check is not a reason to bypass signature verification.

What differs from Windows?

Yas Browser: tabs, search, bookmarks, history, lazy session restore, sleeping eligible background pages, Stealth views, file-save downloads, zoom, and print. This first port does not include Windows extensions, password/autofill import, ad-filtering parity, screenshot/PDF export, resumable or tray downloads, or full native menu/shortcut parity. Sleeping tabs may lose unsaved page content and per-tab navigation history. Stealth tabs stay awake and are excluded from history and session restore. Closing the app can stop downloads.

Yas Mail: the existing macOS port with account tabs, manual account setup, Keychain support, and a demo workspace. Gmail/Microsoft publisher OAuth activation remains pending. Live-provider send/receive, detached windows, attachment dialogs, notifications, and optional local AI still need interactive testing. Expanded features are a work in progress.

What has been checked?

Release automation requires native Rust tests, Mail’s JavaScript tests, a real frontend/native launch handshake for each packaged app, a synthetic Keychain save/read/delete for Mail, and signed whole-bundle update installation with damaged-package rejection. These checks do not establish feature parity, comprehensive usability, or live email-provider compatibility. No comparative RAM or CPU percentage is claimed for the Mac previews.
