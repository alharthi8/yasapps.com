Both apps use Rust for their desktop core. Yas Mail uses Tauri; Yas Browser uses Tao and Wry. Purposeful foundations for everyday tools.

02 / THE BROWSER

Tabs that take a rest.

Yas Browser loads restored tabs on demand and unloads eligible background pages after two minutes. Your saved tab URLs remain ready to reopen.

Windows previews use Microsoft’s WebView2. Mac previews use Apple’s WKWebView. A Rust desktop core paired with the platform’s web engine, without bundling a separate Chromium engine.

A FEW THINGS TO KNOW

Clear from the start.

Are the apps free to download?+

Yes. The current Windows and experimental Apple Silicon macOS previews are free to download and try. You don’t need to register your email to download them.

Are both apps really built with Rust?+

Yes. Both apps have a Rust desktop core. Yas Mail uses Tauri 2; Yas Browser uses Tao and Wry. Windows uses Microsoft Edge WebView2 and macOS uses Apple’s WKWebView for web rendering. The rendering engines are not written by Yas Apps.

Can I download a macOS version?+

Yes. Select macOS in the downloads section for experimental Apple Silicon previews of both apps. These are not Apple notarized and Gatekeeper may block opening. Intel is not available. Yas Browser’s first Mac port has fewer features than Windows. Read the Mac preview guide before installing.

Can I connect Gmail or Microsoft 365 to Yas Mail?+

Publisher configuration and live verification of Gmail, Outlook, and Microsoft 365 sign-in are still in progress. The downloadable preview has a demo workspace and manual account setup. Manual setup depends on your provider’s supported protocols and authentication rules.

How will app updates work?+

Install the current preview for your platform once. Both apps check GitHub on startup and offer Check for app updates in Settings (the menu panel in Yas Browser on Mac). Approve the download to apply a verified update, then fully quit and reopen when convenient. Mac updates replace the complete app bundle and use a separate Apple Silicon channel. Update signatures verify authenticity; Windows publisher signing and Apple notarization are separate. Install Mac apps into a writable Applications folder.

Where is the open-source code?+

The Windows and macOS preview source is public: Yas Browser on GitHub and Yas Mail on GitHub. Yas-owned code uses the MIT license; third-party components retain their own licenses. Each repository includes contribution guidance and an issue tracker.

WINDOWS PREVIEW 0.4.6

Yas Browser

Windows 10/11 x64. Uses Microsoft Edge WebView2; the installer offers its bootstrapper if missing and requires internet to download the runtime.

  • Tabs, bookmarks, history, downloads, and session restoration.
  • Sleeping background tabs and lazy tab loading.
  • Ad/tracker filtering and a separate Stealth session.
  • The Windows installer is not publisher-signed.

Sleeping tabs reload when reopened; unsaved page content can be lost. Stealth doesn’t hide activity from websites or your network.

WINDOWS PREVIEW 0.3.1

Yas Mail

A Rust and Tauri desktop mail client. This download is an early preview with a demo workspace and manual account setup.

  • Account tabs, detachable windows, and account colors.
  • Manual IMAP, POP3, and SMTP settings.
  • Gmail, Outlook, and Microsoft 365 publisher sign-in is not yet activated.
  • Features under development may differ from this installer.

This is a mail client for existing accounts, not a service that creates @yasapps.com mailboxes. The installer is not publisher-signed.

EXPERIMENTAL MACOS PREVIEW 0.4.7

Yas Browser for Mac

Apple Silicon (M1 or newer), using Apple’s WKWebView. No Intel package. The macOS 13 build target has not been validated on every older OS release.

Tabs, search, bookmarks, history, lazy session restore, sleeping background pages, Stealth views, file-save downloads, zoom, and print.

This first port does not include Windows extensions, password import, ad-filtering parity, screenshot/PDF export, resumable or tray downloads, or full native menu/shortcut parity. Sleeping tabs can lose unsaved page content. Closing the app can stop downloads.

Not Apple notarized. Uses an ad-hoc development signature. Gatekeeper may block opening. Extract the ZIP and move the app into a writable Applications folder before using in-app updates. Read the Mac preview guide ↗
