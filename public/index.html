WHY WE BUILD WITH RUST

Rust at the core.
Thoughtful by design.

Rust gives us control over memory and how our desktop core runs. Paired with focused design, it is the foundation of Yas Browser.

01 / THE FOUNDATION

Rust at the core.

Yas Browser uses Rust with Tao and Wry for its desktop core. A native foundation for a focused browsing experience, with open-source code you can explore.

Rust · Native desktop
02 / THE BROWSER

Tabs that take a rest.

Yas Browser loads restored tabs on demand and unloads eligible background pages after two minutes. Your saved tab URLs remain ready to reopen.

Lazy restore · Sleeping tabs
03 / THE ENGINE

Use what’s already there.

Windows previews use Microsoft’s WebView2. Mac previews use Apple’s WKWebView. A Rust desktop core paired with the platform’s web engine, without bundling a separate Chromium engine.

WebView2 · WKWebView

Performance, with context.

A FEW THINGS TO KNOW

Clear from the start.

Is Yas Browser free to download?+

Yes. The experimental Apple Silicon Mac preview is free to download without registering. Windows Browser 1.0 remains coming soon during security review and release validation. Community support is optional.

Is Yas Browser built with Rust?+

Yes. Yas Browser uses Rust with Tao and Wry for its desktop core. Windows uses Microsoft’s WebView2 and macOS uses Apple’s WKWebView for web rendering. The rendering engines are supplied by the platform; Rust alone does not guarantee lower RAM or CPU use.

Does the browser already include unified email?+

Not yet. A unified email client built directly into Yas Browser is on the roadmap. It is not included in the current Windows or Mac previews. We will share provider compatibility, capabilities, and availability after implementation and testing.

Can I download a macOS version?+

Yes. Yas Browser 0.4.7 is an experimental Apple Silicon preview with fewer features than Windows. It is not Apple notarized. Read the Mac installation guide and limitations before downloading.

What happened to Yas Mail and other products?+

Yas Browser is our flagship and our current focus. Yas Mail, our standalone email client, remains in the pipeline with downloads coming soon. It is separate from the unified email feature planned for Yas Browser.

How will browser updates work?+

The Mac preview checks GitHub at startup and from its menu panel → Check for app updates. Approve a signed update, then fully quit and reopen. Install the preview in a writable Applications folder. These update signatures are separate from Apple notarization. Windows releases remain in validation.

Where is the open-source code?+

Explore Yas Browser on GitHub to read the code, report issues, or contribute. Yas-owned code uses the MIT licence; third-party components retain their own licences. Source for Yas Mail is linked in the pipeline section.

MACOS · EXPERIMENTAL PREVIEW 0.4.7

Yas Browser for Mac

Apple Silicon (M1 or newer), using Apple’s WKWebView. No Intel package. The macOS 13 build target has not been validated on every older OS release.

Tabs, search, bookmarks, history, lazy session restore, sleeping background pages, Stealth views, file-save downloads, zoom, and print.

This first port does not include Windows extensions, password import, ad-filtering parity, screenshot/PDF export, resumable or tray downloads, or full native menu/shortcut parity. Sleeping tabs can lose unsaved page content. Closing the app can stop downloads.

Not Apple notarized. Uses an ad-hoc development signature. Gatekeeper may block opening. Extract the ZIP and move the app into a writable Applications folder before using in-app updates. Read the Mac preview guide ↗

This Mac preview is separate from the Windows 1.0 release candidate. Automated native-launch and signed bundle-update checks passed; broader interactive testing remains ongoing.
