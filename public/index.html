WHY WE BUILD WITH RUST

Rust at the core.
Thoughtful by design.

Rust gives us control over memory and how our desktop core runs. Paired with focused design, it is the foundation of Yas Browser.

01 / THE FOUNDATION

Rust at the core.

Yas Browser uses Rust with Tao and Wry for its desktop core. A native foundation for a focused browsing experience, with open-source code you can explore.

Rust · Native desktop
02 / THE BROWSER

Tabs that take a rest.

Yas Browser loads restored tabs on demand and unloads eligible background pages after two minutes. Your saved tab URLs remain ready to reopen.

Lazy restore · Sleeping tabs
03 / THE ENGINE

Use what’s already there.

Yas Browser for Windows pairs its Rust desktop core with Microsoft’s WebView2. It uses the platform’s web engine without bundling a separate Chromium engine.

Rust · WebView2

GOOD QUESTIONS. STRAIGHT ANSWERS.

Before you hit download.

What can I download right now?+

Yas Browser for Windows v0.4.9 is available now. It is a free desktop preview for Windows 10/11, 64-bit. Download for Windows ↗. macOS is coming soon. Yas Mail, Yas Connect, and Yas Agent are all coming soon.

Is Yas Browser free and open source?+

Yes. Download the Windows browser for free and explore its source on GitHub. Yas-owned code uses the MIT licence; third-party components retain their own licences. Supporting the community is optional.

What’s special about the Rust core?+

Rust gives us control over the desktop core. Yas Browser uses Tao and Wry with WebView2 on Windows. Sleeping tabs and lazy session restore help manage which pages stay loaded. We do not claim a universal RAM or CPU percentage advantage over other browsers.

Does the Windows download include unified email?+

Not yet. The built-in unified email client is in development for a future browser release. It is not part of v0.4.9. Yas Mail is a separate standalone product in the pipeline.

When will macOS and the other products launch?+

macOS, Yas Mail, Yas Connect, and Yas Agent are coming soon. We have not announced launch dates. Select the products you want to follow in the update form and we’ll share news when they’re ready.

How do Windows updates work?+

Install the Windows setup package once. Later releases can be checked from Settings → Check for app updates. The updater verifies signed update metadata and the full installer. Quit and reopen when prompted after applying an update. Update signatures are separate from Windows publisher signing.

Is Stealth mode anonymous browsing?+

Stealth uses a separate private session that ends when the window closes. It does not hide your activity from websites, your internet provider, or your network administrator.

WINDOWS · AVAILABLE NOW · V0.4.9

Yas Browser for Windows

Free Windows 10/11 x64 desktop preview. Uses Microsoft WebView2. The setup package can install the WebView2 runtime if needed; that step requires internet access.

  • Tabs, bookmarks, history, sleeping background pages, and lazy session restore.
  • Ad/tracker request filtering and a separate Stealth session.
  • Signed in-app update checks and verified full-installer updates.
  • Optional local AI sidebar; model setup is a separate download and can use substantial CPU and RAM.

Sleeping tabs reload when reopened; unsaved page content can be lost. The installer is not Windows publisher-signed.
