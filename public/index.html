A FEW THINGS TO KNOW

Clear from the start.

Are the apps free to download?+

Yes. The current Windows previews are free to download and try. You don’t need to register your email to download them.

Are both apps really built with Rust?+

Yes. Both apps have a Rust desktop core. Yas Mail uses Tauri 2; Yas Browser uses Tao and Wry. On Windows, web rendering is handled by Microsoft Edge WebView2, rather than a new rendering engine written entirely in Rust.

When can I download a macOS version?+

macOS is on the roadmap. Both applications currently have Windows-specific components that need porting and testing. Register above and select macOS to hear when a build is ready. We haven’t announced a release date.

Can I connect Gmail or Microsoft 365 to Yas Mail?+

Publisher configuration and live verification of Gmail, Outlook, and Microsoft 365 sign-in are still in progress. The downloadable preview has a demo workspace and manual account setup. Manual setup depends on your provider’s supported protocols and authentication rules.

How will app updates work?+

Install the current Windows preview once to enable signed GitHub updates. Both apps check on startup and offer Settings → Check for app updates. Approve the download to apply the verified update, then fully quit and reopen when convenient. The current session stays open. These signatures verify update authenticity; Windows publisher signing is separate. macOS updates are not available yet.

Where is the open-source code?+

The Windows preview source is public: Yas Browser on GitHub and Yas Mail on GitHub. Yas-owned code uses the MIT license; third-party components retain their own licenses. Each repository includes contribution guidance and an issue tracker.

WINDOWS PREVIEW 0.4.6

Yas Browser

Windows 10/11 x64. Uses Microsoft Edge WebView2; the installer offers its bootstrapper if missing and requires internet to download the runtime.

  • Tabs, bookmarks, history, downloads, and session restoration.
  • Sleeping background tabs and lazy tab loading.
  • Ad/tracker filtering and a separate Stealth session.
  • The Windows installer is not publisher-signed.

Sleeping tabs reload when reopened; unsaved page content can be lost. Stealth doesn’t hide activity from websites or your network.

A Rust and Tauri desktop mail client. This download is an early preview with a demo workspace and manual account setup.
