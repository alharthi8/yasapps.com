Rust gives us control over memory and how our desktop core runs. Paired with focused design, it is the foundation of both Yas apps.

01 / THE FOUNDATION

Rust at the core.

Both apps use Rust for their desktop core. Yas Mail uses Tauri; Yas Browser uses Tao and Wry. Purposeful foundations for everyday tools.

Rust · Native desktop
02 / THE BROWSER

Tabs that take a rest.

Yas Browser loads restored tabs on demand and unloads eligible background pages after two minutes. Your saved tab URLs remain ready to reopen.

Lazy restore · Sleeping tabs
03 / THE ENGINE

Use what’s already there.

Windows previews use Microsoft’s WebView2. Mac previews use Apple’s WKWebView. A Rust desktop core paired with the platform’s web engine, without bundling a separate Chromium engine.

A FEW THINGS TO KNOW

Clear from the start.

Are the apps free to download?+

Yas Browser’s experimental Apple Silicon Mac preview is free to download without registering. Windows Browser 1.0 and Yas Mail remain coming soon. You can register for release news.

Are both apps really built with Rust?+

Yes. Both apps have a Rust desktop core. Yas Mail uses Tauri 2; Yas Browser uses Tao and Wry. Windows uses Microsoft Edge WebView2 and macOS uses Apple’s WKWebView for web rendering. The rendering engines are not written by Yas Apps.

Can I download a macOS version?+

Yes, Yas Browser has an experimental Apple Silicon preview. It is version 0.4.7, has fewer features than Windows, and is not Apple notarized. Read the Mac installation guide and limitations before downloading. Yas Mail for Mac remains coming soon.

Can I connect Gmail or Microsoft 365 to Yas Mail?+

Publisher configuration and live verification of Gmail, Outlook, and Microsoft 365 sign-in are still in progress. The development build has a demo workspace and manual account setup. Manual setup depends on your provider’s supported protocols and authentication rules.

How will app updates work?+

The Mac Browser preview checks GitHub at startup and from its menu panel → Check for app updates. Approve a signed update, then fully quit and reopen. It verifies the update ZIP and replaces the full app bundle. Install it in a writable Applications folder. These update signatures are separate from Apple notarization. Windows Browser 1.0 and Yas Mail releases remain in validation.

Where is the open-source code?+

The Windows and macOS preview source is public: Yas Browser on GitHub and Yas Mail on GitHub. Yas-owned code uses the MIT license; third-party components retain their own licenses. Each repository includes contribution guidance and an issue tracker.

MACOS · EXPERIMENTAL PREVIEW 0.4.7

Yas Browser for Mac

Apple Silicon (M1 or newer), using Apple’s WKWebView. No Intel package. The macOS 13 build target has not been validated on every older OS release.

Tabs, search, bookmarks, history, lazy session restore, sleeping background pages, Stealth views, file-save downloads, zoom, and print.

This first port does not include Windows extensions, password import, ad-filtering parity, screenshot/PDF export, resumable or tray downloads, or full native menu/shortcut parity. Sleeping tabs can lose unsaved page content. Closing the app can stop downloads.

Not Apple notarized. Uses an ad-hoc development signature. Gatekeeper may block opening. Extract the ZIP and move the app into a writable Applications folder before using in-app updates. Read the Mac preview guide ↗

This Mac preview is separate from the Windows 1.0 release candidate. Automated native-launch and signed bundle-update checks passed; broader interactive testing remains ongoing.
